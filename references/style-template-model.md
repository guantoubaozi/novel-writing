# 风格模板模型：定性维度、量化辅助与回测

> **本地样本与合规边界（先读）**：本文只定义如何从获许可、公版或作者自有的本地样本抽象风格。`raw/` 不进入发布物；不复制原文长段，不把模板用于重建原作。内部短摘句只在本地作为锚点，发布或共享前删除/改写。

实现对应 [scripts/extract_style.py](../scripts/extract_style.py) 与 [scripts/test_style_template.py](../scripts/test_style_template.py)。本模型不替任何特定书籍下定性结论；每本书的结论必须由 agent 依据实际样本填写。

## 1. 分层原则

模板分为“定性主体”和“量化辅助”。定性层描述读者可感知、可迁移的写法；量化层只提供粗略信号和回测距离。不要把辅助数字变成必须命中的句长、段长或标点配额。

导入的对话部分是作者整体的基线语域与节奏，不是人物声线表。项目已有 per-character voice、character-context 和 name-blind test 继续决定角色之间的差异，模板不得覆盖它们。

## 2. §4.1 定性维度（模板主体）

Agent 阅读多章 `raw/` 和量化底稿后填写每项：**观察**（倾向及范围）、**证据**（章节/场景类型或极短内部锚点）、**边界**（例外、置信度和不应泛化之处）。不写“这本书一定……”式无证据结论。

### 2.1 叙事层

1. **视角与距离**：近距离内视、有限视角、疏离全知等在不同场景的切换；记录心理活动贴近程度、叙述者是否评价人物。
2. **自由间接引语**：第三人称叙述是否滑入人物用词、判断和感受而不加引号/“他想”；观察出现条件、密度和与视角距离的关系。
3. **节奏质感**：长短句如何交替，流水句与短促句的整体手感，停顿和段落推进如何制造张力。只做定性描述，不把平均句长或方差写成目标。
4. **描写笔触**：白描、克制的选择性细节，或浓墨重彩、层层铺陈；说明细节偏向人物、环境、动作还是物件，以及镜头收放。
5. **感官偏好与意象母题**：视、听、触、嗅、味等感官的相对偏好；反复出现的光影、天气、声音、材质等意象如何服务情绪或主题。不要把单个意象提升为全书母题。
6. **情绪呈现（show/tell）**：情绪是直接命名、解释，还是通过身体、动作、环境反应和选择间接呈现；记录两者在高压/日常场景的差异。
7. **语域**：书面、口语、古白话或混合基线；雅俗倾向、词语时代感和叙述/对白之间的落差。语域描述不得冒充人物专属方言。
8. **留白与含蓄**：信息是否延迟、暗示或省略，叙述是否容许读者补全；区分有意留白与样本缺失，写明适用场景。

### 2.2 对话层（作者整体基线）

1. **对话标签**：纯“说”类标签、带动作/副词的复杂提示语、无标签对白的整体倾向；只描述作者的标注习惯，不给角色逐一分配标签。
2. **动作插入（beat）**：动作、表情、环境反应与对白的交织位置、频率和作用；避免把每句对白都强行配动作。
3. **潜台词浓度**：对白信息是直说、绕说、试探还是互相错位；说明读者需要推断的层级，不能把“含蓄”当成删掉必要信息。
4. **口语化/语域基线与方言标记**：对白相对叙述的口语程度、句式简省、礼貌距离及方言标记是否节制；不据此覆盖角色自己的 voice。
5. **打断、省略、停顿**：破折号、省略号、未完句、重复和抢话的手感；描述其叙事功能，不设标点数量配额。

## 3. 固定 qualitative slots 与 Agent 边界

回测脚本固定七个槽位（英文键/中文标签如下），用于让不同模板、不同书的定性评审可比较：

| 固定键 | 中文标签 | 覆盖范围 |
|---|---|---|
| `viewpoint` | 视角距离 | 视角类型、心理贴近度、自由间接引语 |
| `rhythm` | 节奏 | 长短句交替的质感、推进、停顿；不填句长统计 |
| `description` | 描写笔触 | 白描/浓墨、细节选择、镜头收放 |
| `sensory_imagery` | 感官/意象 | 感官偏好与可重复但有证据的意象模式 |
| `show_tell` | show/tell | 情绪和信息的直接命名与间接呈现 |
| `register_ellipsis` | 语域/留白 | 叙述/对白语域、雅俗、含蓄和信息留白 |
| `dialogue_subtext` | 对话标签/beat/潜台词/停顿 | 五项对话层维度的合并评审槽位 |

Agent 可以在槽位内补充例外、场景条件、证据类型和置信度；必须覆盖所有槽位，缺证据时标记“待验证”，不得用常识填空。Agent 不负责计算指标、改写脚本、发明章节或把原文粘贴进报告。若要改变槽位定义，应先更新模型和评审协议，而不是在一次评分中临时换标准。

## 4. §4.2 量化辅助维度

`extract_style.py` 输出 `metrics.json`。这些维度用于粗略区间、章节对比和 round-trip 距离，不是写作硬约束；方法受中文分句、标记词和可选分词器影响，应结合原文阅读解释。

### 4.1 叙述与动作、场景与概述

- **描写 vs 动作相对占比**：按感官/形容标记命中句与动作动词命中句的字符数粗分；同一句可同时命中，结果只说明高/中/低倾向。
- **场景 vs 概述相对占比**：按场所、时空和感官标记命中句粗分场景，其余作为概述近似；不是叙事学精确分类。

### 4.2 修辞、词汇与标点

- **比喻/排比/反问相对频率**：比喻用“像/如同/仿佛”等标记，排比用重复逗号结构的轻量近似，反问用疑问标点和反问触发词；报告计数、每句近似频率和倾向。
- **成语密度**：连续四个汉字作为候选上界，受专名、固定短语和分词误差影响。
- **标点习惯**：破折号、略号、感叹号按每千非空白字符计数，作为相对频率信号。
- **词汇丰富度**：type-token ratio；优先使用可选 `jieba`，缺失时退化为汉字级 token，不能跨分词方法直接比较绝对值。

### 4.3 对话信号

- **对白占叙述字数比**：成对引号内容字符数与非对白字符数的粗比，不等同于角色发言量。
- **对话标签风格分布**：对白后短窗口内识别纯“说”、复杂提示语、无标签三类，输出计数、比例和倾向；识别失败应视为近似，不得当作人工标注。

### 4.4 明确不包含的四项

量化层**明确不计算、不过滤、也不作为距离目标**：

- 平均段长；
- 单句成段占比；
- 平均句长；
- 句长方差。

代码中的 `EXCLUDED_DIMENSIONS` 和回测距离都会跳过这四项。这样做是为了避免把自然节奏压扁成死板的长度配额。

## 5. 三种模板形态

三种形态共享同一组源样本、定性 slots 和 `metrics.json`，只改变“给写作者/生成器的呈现方式”。每种形态都必须明确用途、输入和禁止事项。

### 5.1 `metrics`（指标型）

- **用途**：把量化倾向转成检查清单和回测输入，快速发现生成片段与参考区间的偏离。
- **输入**：参考 `metrics.json`、已填写的 `template.md` 叙事/对话层、目标片段及其同套指标。
- **禁止**：把高/中/低或任何数值当硬约束；补写脚本未测量的定性结论；要求命中平均段长、平均句长等四项排除指标；复制原文。

### 5.2 `quotes`（摘句锚点型）

- **用途**：从 `quote_candidates.json` 中选极短、能帮助 agent 记住节奏或意象的本地内部锚点，并回指抽象规则。
- **输入**：候选 JSON、本地 `raw/` 上下文、已填写的定性模板；必要时记录章节/场景类型而非正文。
- **禁止**：选跨段或过长片段；把候选原文写入发布物；以摘句替代跨章观察；把角色口吻当作作者基线；用摘句重建原作。

### 5.3 `rules`（规则指令型）

- **用途**：把已验证的定性观察改写为可执行的起草/修订指令，供同一场景试写和 round-trip 复用。
- **输入**：`template.md` 的定性观察、`metrics.json` 的辅助信号、调用方提供的场景草稿和人物设定。
- **禁止**：伪造未观察到的风格结论；要求固定句长、段长或标点命中；把规则写成逐句仿写；覆盖项目的 per-character voice/character-context；分发原文。

三形态不是三个互斥的真理：A/B 只比较在同一场景和相同评审条件下哪种呈现更接近参考风格。

## 6. Hold-out 与风格距离

### 6.1 末两章留出

`test_style_template.py` 按章节文件名排序，将最后两章作为 hold-out，其余章节作为抽模板/训练集；因此默认的“末两章”是**排序后的最后两份 `.txt`**，命名应保持章节顺序。少于三章时返回 `skipped`，不能把训练集自身当验证集。报告应列出训练章、留出章以及每个未抓准的辅助维度。

### 6.2 量化距离

参考 `metrics.json` 与候选片段的共同数值叶子做归一化差异，单项距离限制在 `[0,1]`，共同叶子的平均值为 `quantitative_distance`。被排除的四项、方法说明、倾向文字和非数值字段不参与距离。它回答“可测的粗略信号有多接近”，不回答“文学上是否相像”。

### 6.3 定性 rubric 与总距离

Agent 为七个固定 slots 各给 `0–100`（脚本归一化为 `0–1`）的相似度，并简述证据和不确定性。默认槽位等权平均，形成 `qualitative_distance = 1 - 平均相似度`。有完整定性评分时，总距离为：

```text
weighted_total = 0.35 × quantitative_distance
               + 0.65 × qualitative_distance
```

定性占 65%，高于量化的 35%；这是为了避免可测但粗糙的词频/标点信号压过视角、节奏、潜台词等核心判断。缺少任一槽位时，脚本标记 `pending_agent_judge`，只能按量化距离 provisional 排序，不得宣称最终相似度。

## 7. A/B 自动选优与经验记录

1. 用相同场景、人物约束、输出长度范围，分别按 `metrics`、`quotes`、`rules` 形态生成试写；评审输入隐藏形态名称。
2. 脚本对三个样本分别计算量化距离；若定性槽位完整，再按 `weighted_total` 从小到大排序，选择 `best_template`。并列时按固定形态顺序稳定处理，避免随机选优。
3. 结果写入 `test-report.md`：hold-out 状态、三形态距离、定性槽位状态、总榜单和自动选择结果。定性未完成则显式写 provisional。
4. “哪类形态整体更有效”只能作为跨书/跨场景的经验记录：记录样本数、场景条件、是否完整定性评审、失败原因和适用范围；不要从单本书或一次 A/B 推导普遍结论。

## 8. 从模型到项目 voice

通过回测后，将 `template.md` 中的抽象叙事/对话基线（以及必要的规则型检查项）人工合并到项目 `style/voice.md`。删除/替换内部摘句，保留来源许可和版本记录在本地即可。应用时：

- 模板约束作者层行文的视角、节奏、描写和对话基线；
- per-character voice 仍约束每个角色的词汇、语气和差异；
- 发现模板与角色设定冲突时，以项目角色规则和场景需求为准，并在回测记录偏差；
- 不把 `raw/`、长摘句、受限 URL 内容复制到 `voice.md` 或任何发布物。
