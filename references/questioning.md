# Development Questioning

## Default behavior

Read every newly supplied fiction passage or note before asking anything. When the newly supplied material requires development decisions, ask 3–5 questions by default after reading. Execute status and audit requests without default questions; ask only when findings expose a material author decision. Skip the question round when the author explicitly asks to skip questions. When the author asks for immediate output or drafting, state necessary assumptions and produce it before offering follow-up questions.

Anchor every question in observed material. For each question:

1. Quote or accurately paraphrase one specific supplied detail.
2. Expose a choice, gap, tension, consequence, or sensory opportunity.
3. State briefly how the answer would change the story.
4. Leave viable answers open; do not push a preferred answer.

Never ask “How do you want the story to develop?” unless the question names a concrete observed fork and its competing consequences.

## Select lenses

Choose only lenses that can materially change the requested work. Mix lenses so the set tests multiple dimensions rather than repeating one concern.

### Premise

- Test whose motivation turns the premise into action.
- Clarify the causal event that makes the old equilibrium impossible.
- Define personal, relational, and external stakes of failure.
- Identify the premise promise that later reversals must fulfill.

### Character

- Contrast stated desire with behavior, fear, wound, or boundary.
- Test agency: identify the choice only this character can make.
- Probe relationship pressure, concealed needs, and asymmetric knowledge.
- Ask for embodiment when emotion lacks gesture, sensation, or physical cost.

### Worldbuilding

- Clarify a setting rule, its limit, enforcement, and cost.
- Test how institutions or environments alter ordinary behavior.
- Separate public belief, private truth, and character knowledge.
- Seek one sensory detail that makes the rule tangible in the scene.

### Outline

- Verify cause and effect between adjacent beats.
- Test escalation, reversal, aftermath, and changed relationships.
- Locate setup needed for later foreshadowing or payoff.
- Challenge beats that move the plot without a character decision.
- When the optional eight-beat lens would clarify the outline, distinguish opportunity from guaranteed success and ask why the character believes the path is credible.
- Ask whether disruption changes the situation while reinterpretation changes its meaning; let one event do both when separation adds no value.
- Test the consequential choice after a turn, while remembering that the decision need not be a counterattack and may instead be retreat, refusal, sacrifice, compromise, or error.

### Chapter

- Clarify the viewpoint character's immediate goal and opposition.
- Identify the scene turn, cost, and consequential outcome.
- Test whether information asymmetry creates intended tension or accidental confusion.
- Ask what physical or relational aftermath must carry forward.

### Mystery

- Distinguish clues available to readers, viewpoint characters, and the author.
- Test alternate interpretations without invalidating fair-play evidence.
- Place foreshadowing early enough to be remembered but not decoded automatically.
- Track how each reveal changes motivation, stakes, suspicion, or relationships.

## Compose the set

Cover the most relevant combination of motivation, causality, stakes, relationships, embodiment, setting rules, information asymmetry, aftermath, and foreshadowing. Prefer fewer high-leverage questions over a complete checklist. Tie every question to what the author actually supplied.
