# Security Policy

## Supported versions

Security fixes are guaranteed only for the latest release and the default branch.

## Reporting a vulnerability

Report the following issues through GitHub **Private vulnerability reporting** or a private Security Advisory. Do not open a public issue containing exploit details:

- Path traversal, symlink escape, or writes outside the project.
- Structured-state validation bypasses or partial writes.
- Author-only information leaking into reader dashboards.
- HTML injection or script execution.
- Unauthorized overwriting of manuscript, state, or visualization files.

Include the affected version, reproduction steps, expected impact, and a minimal test case. Coordinate public disclosure only after maintainers confirm and release a fix.
